THE FLOW

What happens to your data

Three algorithms. Different mathematical approaches. Different security properties.

01 / RSA
⌘

Public & private keys

A public key is used for encryption and a matching private key is used for decryption. The supplied Python example demonstrates textbook RSA on short messages.

PUBLIC KEY→CIPHERTEXT→PRIVATE KEY
02 / AES-GCM
◈

Encrypt & authenticate

A shared 256-bit key and a fresh 12-byte nonce produce ciphertext and a 16-byte authentication tag. The tag is checked before plaintext is released.

KEY + NONCE→CIPHERTEXT+TAG
03 / HILL
▦

Matrix transformation

Letters are mapped to numbers, grouped into blocks and multiplied by an invertible key matrix modulo 26. Decryption uses the inverse matrix.

TEXT BLOCK→MATRIX KEY→LETTER BLOCK

SECURITY CHECKLIST

Protect the key. Protect the data.

Encryption is only as safe as the way keys and inputs are handled.

⌑
◉

Never expose private keys

Do not paste private keys into public websites, screenshots, chat messages or client-side source code. Keep them on a trusted backend or secure local storage.

↻

Never reuse an AES-GCM nonce

Generate a fresh unique nonce for every encryption under the same key. Reuse can catastrophically undermine confidentiality and authentication.

✓

Verify before trusting output

For AES-GCM, reject data if tag verification fails. Never display or use unauthenticated plaintext.

⌁

Use modern RSA padding

The included RSA code uses textbook RSA without OAEP padding. It is educational only; do not use it to protect real or sensitive data.

▤

Do not treat Hill as secure

Hill cipher is a classical teaching cipher and is not suitable for protecting confidential information.

⛨

Keep secrets out of Git

Never commit keys, tokens or decrypted sensitive data. Use environment variables and secret-management tools for server-side credentials.

Important: The project's README describes this repository as a learning project, not production cryptography. Use vetted protocols and libraries for real-world security.
